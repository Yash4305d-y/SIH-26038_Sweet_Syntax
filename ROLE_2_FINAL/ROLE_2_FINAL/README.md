# ROLE 2 — DATASET RESEARCH & IMAGE PROCESSING

## Purpose

This module contains the dataset research and retinal image-processing
components developed for the Diabetic Retinopathy screening system.

The module provides retinal image quality assessment, preprocessing,
retinal structure analysis, lesion detection, feature extraction, and
the finalized inference interface.

---

## Role Responsibilities

### Dataset Research

- Identification and comparison of suitable diabetic retinopathy datasets
- Dataset classes and labels
- Dataset size
- Image quality
- Accessibility
- Licensing and access restrictions
- Dataset suitability for AI development

### Image Processing

- Retinal image preprocessing
- Image enhancement
- Normalization
- Image Quality Assessment
- Retinal structure extraction
- Segmentation-related processing
- Lesion detection
- Feature extraction
- Identification of retinal-image challenges

## Main Integration Interface

The main MATLAB entry point is:

    final_DR_inference.m

Example:

    imagePath = 'path_to_retinal_image.png';
    result = final_DR_inference(imagePath);

The function returns the screening result together with extracted
retinal evidence and model information.

---

## Returned Result

Important result fields include:

    result.status
    result.decision
    result.drProbability
    result.threshold
    result.features
    result.featureNames
    result.summary
    result.pipeline

## MATLAB Setup

Add the MATLAB code folder and its subfolders to the MATLAB path:

    addpath(genpath('path_to_ROLE_2_FINAL/02_MATLAB_CODE'));

Then run:

    result = final_DR_inference(imagePath);

---

## Important Integration Note

The MATLAB functions and the final model are a matched implementation.

Do not replace individual preprocessing, segmentation, lesion-feature,
or feature-engineering functions without revalidating the final model.

The model expects the feature representation generated by this module.
