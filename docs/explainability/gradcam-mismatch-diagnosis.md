# Grad-CAM Mismatch Diagnosis

## The 7 Mismatches
During the generation of the 439-image Grad-CAM dataset, 7 specific images produced predictions that differed from the authoritative evaluation (`baseline_test_predictions.csv`):
* `67f5d89da548.png`: Expected 2, got 4
* `76be29bb30b2.png`: Expected 1, got 2
* `92d8a7c8e718.png`: Expected 2, got 3
* `ab1c20a94f3f.png`: Expected 2, got 0
* `b94c58d063bf.png`: Expected 4, got 2
* `c102db7634d8.png`: Expected 2, got 1
* `c9ea9d5eab65.png`: Expected 2, got 3

## Root Cause
The discrepancy stems from a subtle algorithmic difference in how MATLAB's `augmentedImageDatastore` resizes images compared to a raw `imresize` command.
- **Original Evaluation (`evaluateBaselineResNet50.m`)**: Passed the entire test set through an `augmentedImageDatastore([224 224], imdsTest)`. The datastore manages the internal file I/O, resizing interpolation, and datatype preservation.
- **Grad-CAM Full Script (`gradcamBaselineFull.m`)**: Explicitly used `imread()` followed by a standard `imresize(img, [224, 224])`.

## Evidence
A localized diagnostic test was run on the first mismatched image, `67f5d89da548.png`:
1. **Original Datastore Method**: Output prediction = **2**
2. **Explicit `imresize` Method**: Output prediction = **4**

Comparing the raw arrays generated by both methods revealed a **maximum pixel difference of 15.0** (on a 0-255 scale). Because this baseline neural network is relatively uncalibrated, this pixel-level perturbation shifted the softmax confidence scores just enough to flip the top predicted class on these 7 borderline images.

## Exact Preprocessing Difference
While both methods nominally resize the image to `[224, 224, 3]`, `augmentedImageDatastore` utilizes a slightly different internal resizing or anti-aliasing pipeline compared to the default parameters of `imresize`.

## Required Fix
To guarantee 100% fidelity with the original evaluation pipeline, `gradcamBaselineFull.m` must process the image using a single-file `augmentedImageDatastore` rather than `imresize`.

```matlab
% Exact reproduction of the Baseline preprocessing pipeline
imds = imageDatastore(fullPath);
augimds = augmentedImageDatastore([224 224], imds);
dataTbl = read(augimds);
imgAug = dataTbl.input{1};

dlImg = dlarray(single(imgAug), 'SSC');
```

## Authoritative Status
The original `baseline_test_predictions.csv` remains the **authoritative evaluation result**. It represents the exact pipeline executed during the baseline benchmarking. The Grad-CAM script must strictly conform to its pipeline to be valid.
