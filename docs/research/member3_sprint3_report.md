## 1. Executive Summary & Objective

This official report presents the complete execution of Member 3 Sprint 3 domain adaptation on the official **IDRiD B. Disease Grading** dataset. 

The objective of Sprint 3 was to evaluate whether fitting Platt scaling and threshold selection on IDRiD images improves calibration and screening performance of the locked **Baseline ResNet-50** model (`models/baseline_resnet50_smoketest.mat`) without degrading sensitivity or violating operational specificity guardrails.

Following strict Master Plan split isolation rules (40 calibration-fit / 41 held-out validation), the candidate Platt parameters and threshold were fitted exclusively on the 40 calibration-fit images, frozen, and evaluated on the 41 untouched held-out validation images. 

### Final Mechanical Decision: **ROLLBACK**

> [!NOTE]
> **Decision Rationale Summary:**
> On the untouched held-out set ($N=41$), Candidate Platt scaling improved **ECE** ($0.1412$ vs $0.1789$) and **Brier Score** ($0.1193$ vs $0.1319$), while **Sensitivity** remained high at **96.30%** ($26/27$) and **Specificity** improved from **57.14%** ($8/14$) to **64.29%** ($9/14$). However, Specificity ($64.29\%$) fell short of the required **85.0%** operational guardrail. Mechanically applying the predefined promotion rule results in **ROLLBACK**. The locked Baseline ResNet-50 remains the active production baseline.

## 3. Provenance & Previous Experiment Root-Cause Analysis

### 3.1 Historical Invalid Experiment
An earlier Sprint 3 adaptation trial produced a misleading result because it calibrated probabilities generated by a handcrafted morphological feature heuristic (`vessel_ratio`, `ma_count`, `ex_count`) rather than the locked Baseline ResNet-50 model.

### 3.2 Root Cause
Uncropped black background margins in high-resolution IDRiD photos ($4288 \times 2848$) flooded pixel counting functions (`img_gray < 35`), generating artificially high lesion counts ($\sim 200,000$), saturating raw scores, and producing $P_{\text{raw}} = 1.0$ across 100% of images.

### 3.3 Corrected Pipeline Architecture
The corrected Phase 1 execution directly invoked MATLAB R2026a CLI (`matlab -batch`) running `extract_idrid_resnet50_predictions.m`:
$$\text{IDRiD Fundus Image} \longrightarrow \text{RGB Standardization} \longrightarrow \text{imresize([224 224])} \longrightarrow \text{minibatchpredict(net, img224)} \longrightarrow \text{Softmax } (P_0..P_4) \longrightarrow P_{\text{ref, raw}} = P_2 + P_3 + P_4$$

### 3.4 Genuine Prediction Verification
Predictions for all 81 images were verified in `outputs/evaluation/adaptation/idrid_raw_resnet50_predictions.csv`:
- Total Rows: 81 (40 fit, 41 held-out)
- Probability Range: $[0.000101, 0.990930]$ (Finite, continuous distribution)
- Max Sum Deviation ($\sum P_0..P_4 - 1.0$): $1.3 \times 10^{-7}$
- $P_{\text{ref, raw}}$ Identity Error ($P_{\text{ref, raw}} - (P_2 + P_3 + P_4)$): $0.00000000$

## 4. Calibration & Threshold Selection (Calibration-Fit $N = 40$ ONLY)

Candidate Platt scaling was fitted exclusively on the 40 calibration-fit images using `LogisticRegression(C=1e5, solver='lbfgs')`:

$$P_{\text{ref, cand}} = \frac{1}{1 + e^{-(A_{\text{cand}} \cdot P_{\text{ref, raw}} + B_{\text{cand}})}}$$

- **Fitted Candidate Slope ($A_{\text{cand}}$)**: `5.4270`
- **Fitted Candidate Intercept ($B_{\text{cand}}$)**: `-1.8918`
- **Selected Threshold ($\tau_{\text{cand}}$)**: `0.3700` (Optimized on fit set to maximize F1-score subject to sensitivity $\ge 85\%$)
- **Fit Set F1-Score**: `0.8727` | **Fit Set Sensitivity**: `88.89%` (24/27)

### 4.1 Specificity >85% Fit-Set Threshold Investigation
A rigorous threshold sweep across $\tau \in [0.05, 0.95]$ (91 grid points) was executed exclusively on the 40 calibration-fit images to investigate if any threshold could legitimately establish $\ge 85\%$ Specificity without looking at held-out data:
- **Fit Set Sweep Finding**: **ZERO** thresholds on the fit set ($N=40$) achieved both $\text{Sensitivity} \ge 85.0\%$ AND $\text{Specificity} \ge 85.0\%$.
- **Maximum Specificity Threshold**: $\tau = 0.52$ achieved the highest fit-set Specificity ($76.92\%$) while maintaining fit Sensitivity $\ge 85.0\%$ ($85.19\%$). Evaluating $\tau = 0.52$ once on the held-out set ($N=41$) yielded Sensitivity = $81.48\%$ ($22/27$) and Specificity = $78.57\%$ ($11/14$), failing the $\ge 85\%$ guardrail for both metrics.
- **Protocol Conclusion**: No calibration-fit threshold exists that can legitimately achieve $\ge 85\%$ Specificity on the held-out IDRiD subset. In strict compliance with data integrity rules, no further threshold tuning is permitted, and the official decision remains **ROLLBACK**.

### Frozen Parameters:
$A_{\text{cand}} = 5.4270, B_{\text{cand}} = -1.8918, \tau_{\text{cand}} = 0.3700$ were **FROZEN** before inspecting held-out labels.

## 6. Predefined Promotion Rule Evaluation & Decision

The predefined promotion decision rule requires candidate models to satisfy all four operational criteria:

1. $\text{ECE}_{\text{cand}} \le \text{ECE}_{\text{base}}$: **PASS** ($0.1412 \le 0.1789$)
2. $\text{Brier}_{\text{cand}} \le \text{Brier}_{\text{base}}$: **PASS** ($0.1193 \le 0.1319$)
3. $\text{Sensitivity}_{\text{cand}} \ge \max(85\%, \text{Sens}_{\text{base}})$: **PASS** ($96.30\% \ge 85.0\%$)
4. $\text{Specificity}_{\text{cand}} \ge 85.0\%$: **FAIL** ($64.29\% < 85.0\%$)

### Official Decision: **ROLLBACK**

> [!IMPORTANT]
> Candidate adaptation improved calibration error and reduced false positives by 1 image (increasing specificity from 57.14% to 64.29%), but specificity remained below the required 85.0% operational guardrail. Therefore, the locked **Baseline ResNet-50** remains the production model.
